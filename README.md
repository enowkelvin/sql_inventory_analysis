
# Inventory Optimization & Warehouse KPI Analysis (SQL)

## Objective
Use SQL to analyze inventory KPIs and identify reorder risks, fulfillment performance,
stockout drivers, and warehouse efficiency opportunities.

## Tools
- MySQL
- MySQL Workbench

## Key Analysis
- Items below reorder point (stock-out risk)
- Fulfillment rate by category
- Stockout counts and high-risk items
- Inventory value and holding cost estimates
- Picking efficiency and layout performance by zone

## Files
- `sql/inventory_kpi_analysis.sql` – SQL analysis script
